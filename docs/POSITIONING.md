# 产品定位与边界

## 一句话

**GlassesLink 是一个面向 AI 智能眼镜的通用 iOS 客户端**：拍摄时长、编码与处理算法、AI 模型都由用户决定；
当前版本支持 Ray-Ban Meta Gen 2，后续按 `DeviceProfile` 扩展其它品牌。

## 我们在做什么

| 维度 | 我们的做法 |
| --- | --- |
| 连接 | 手机与眼镜直连（蓝牙 LE），会话层加密在 app 内实现；不经第三方服务器 |
| 日常依赖 | 不依赖厂商云端；仅首次登记设备主人时需要厂商账号完成一次 OAuth 授权 |
| 拍摄 | 快门、录像、自动停止时长（30 s – 5 min）、Live 取景、取景中抓拍 |
| 素材 | 原图/原视频按需取回，存进系统相册（视频带封面帧），支持中断重试与真实进度 |
| 设置 | 371 项设备设置可读写，未知值显示「未读取」而不是伪装成关闭 |
| 助手 | 「Hey Meta」的唤醒与语音链路接到用户自选的 OpenAI 兼容模型，回答由眼镜朗读 |
| 隐私 | 可拦截固件升级请求、关闭云端 OTA；日志与诊断包只留在本机 |

## 我们不是什么

- 不是厂商官方 app 的替代品发布渠道：我们不分发任何厂商的二进制或资源。
- 不做任何跳过账号体系的处理：设备主人的登记仍然走厂商账号，一次。
- 不收集遥测、不上传照片、不做云端推理（除非用户自己把模型地址填成云端服务）。

## 为什么做这个

1. **可用性**：官方 app 绑定了固定的助手与固定的拍摄策略，用户无权选择模型、无法延长录制、无法导出原始素材。
2. **可移植性**：同一副眼镜在不同手机上体验差异很大；把协议实现抽成可移植的一层，换手机不等于换体验。
3. **可审计**：加密与协议都在 app 内，代码公开、可自行构建，用户能验证"数据去了哪里"。
