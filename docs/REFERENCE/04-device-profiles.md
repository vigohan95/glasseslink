# 04 · 设备表与能力位

接一个新品牌，需要填的就是下面六列。UI 由能力位生成，不需要为每个型号写一套界面。

## 1. 已支持的型号

| 型号 | 产品号 | 设备类型 | PSM | quirks | 能力位 |
| --- | --- | --- | --- | --- | --- |
| Ray-Ban Meta Gen 1 | 258 | 3 | `0x80` | 0 | 相机、麦克风、音频、按键 |
| Ray-Ban Meta Gen 2 | 262–266 | 3 / 7 | `0x80` | 0（可被 QCS7 变体覆盖） | 相机、麦克风、音频、按键、抓帧 |
| Oakley Meta | 262–266 | 3 / 7 | `0x80` | 0 | 同 Gen 2 |
| Meta Ray-Ban Display | 259 | 5 | `0x80` | 0 | 相机、显示、Neural Band |
| Neural Band | 1537 | 4 | `0x81` | 0 | 手势、无相机 |
| Burbank Audio | — | — | `0x81` | 0 | 仅音频 |

产品号与设备类型从 `status` 的 `pairs` 字段读，不需要硬编码序列号。

## 2. 链路参数

| 项 | 说明 |
| --- | --- |
| PSM | 从 GATT 特征读（见 `01-link-setup.md`），不要写死一个值 |
| 握手通道 | `0x8001`（请求）、`0x0001`（启用） |
| 本地通道起点 | `0x8002`（带 originator 位） |
| 单会话 | 设备同一时刻只接受一个会话；官方 app 连上会接管 |

## 3. quirks

| 值 | 名称 | 影响 |
| --- | --- | --- |
| `0` | 普通 | HKDF info 14 字节；MAC 前缀末字节 `00` |
| `1` | QCS7 | HKDF info 136 字节；MAC 前缀末字节 `01` |

设备可以**不声明** quirks 却按某一套回帧，所以实现里保留"变体交替"：第一帧用候选自证（HMAC 能过就是它），
失败一次后自动换另一套重试，成功后记住。

## 4. 能力位 → UI

| 能力位 | 影响 |
| --- | --- |
| `camera` | 显示「拍摄」「相册」；否则隐藏 |
| `display` | 显示「抬头显示」相关设置 |
| `audio` | 显示音量、通知播报 |
| `inputs` | 显示按键与手势映射 |
| `neuralBand` | 显示手势校准 |

## 5. 固件差异（观测记录）

| 固件 | 观测 |
| --- | --- |
| `72387580077200100` | 社区最早验证的版本 |
| `72387580112400100` | 我们的测试机；EndLinkSetup 不应答（2 秒后继续即可）；RequestEncryption 的版本字段为 `16/17` |
| 更新版本 | 服务集合可能增减（例如无相机机型不提供 svc33），实现要允许"服务缺失"而不是崩 |

读取方式：`status` 的 `deviceStateStart` 里带固件串；不要据此做功能开关，除非确认过行为差异。
